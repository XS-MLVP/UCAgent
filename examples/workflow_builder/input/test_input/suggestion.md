# 文档生成建议

请生成一份面向初次接触 Codex 的工程人员的中文使用介绍文档，全文不少于 1000 字。

## 页面设置

- 纸张大小：A4（210mm × 297mm）
- 页边距：上 25mm，下 25mm，左 28mm，右 22mm（左侧略宽便于装订阅读）
- 页眉：居中显示文档标题（缩写版，不超过 15 字），宋体 9pt，颜色 #888888，下方带 0.5pt 细线
- 页脚：居中显示页码（格式 "第 X 页 / 共 Y 页"），宋体 9pt，颜色 #888888

## 字体规范

### 中文正文
- 字体：宋体（SimSun），12pt
- 行距：固定 22pt
- 段前间距：0pt，段后间距：6pt
- 首行缩进：2 字符（约 24pt）
- 对齐方式：两端对齐（justify）
- 每段字数建议 80–200 字，避免单句成段或超长段落

### 英文/数字混排
- 字体：Times New Roman，与中文同字号
- 中英文之间、数字与中文之间不加空格

### 标题层级
| 层级 | 字体 | 字号 | 加粗 | 颜色 | 对齐 | 段前 | 段后 |
|------|------|------|------|------|------|------|------|
| 一级标题（Heading 1） | 黑体（SimHei） | 18pt | 是 | #1F4E79 | 居中 | 24pt | 12pt |
| 二级标题（Heading 2） | 黑体（SimHei） | 15pt | 是 | #2E75B6 | 左对齐 | 18pt | 8pt |
| 三级标题（Heading 3） | 黑体（SimHei） | 13pt | 是 | #2E75B6 | 左对齐 | 12pt | 6pt |

- 各级标题不使用编号（如 "1."、"1.1"），直接使用描述性标题文字
- 一级标题下方添加 0.75pt 通栏横线，颜色 #1F4E79，线宽占页面宽度的 100%
- 标题与紧随其后的正文之间不留额外空行（由段后间距控制）

## 列表规范

### 无序列表
- 符号：●（实心圆点），缩进与正文首行对齐
- 字体字号与正文相同
- 列表项之间段后间距 3pt
- 每个列表项不超过 3 行

### 有序列表（编号列表）
- 编号格式：阿拉伯数字加英文句点（"1."、"2."），与正文首行对齐
- 操作步骤类内容必须使用有序列表
- 字体字号与正文相同

### 嵌套列表
- 二级列表缩进比一级多 1 个中文字符宽度
- 符号改为 ◦（空心圆点）或 a. b. c.

## 对齐方式规则

| 内容类型 | 对齐方式 |
|----------|----------|
| 封面标题 | 居中 |
| 文档一级标题 | 居中 |
| 二级/三级标题 | 左对齐 |
| 正文段落 | 两端对齐（justify），首行缩进 2 字符 |
| 列表项 | 左对齐，首行缩进与正文一致 |
| 表格标题/题注 | 居中 |
| 图片 | 居中 |
| 图片题注 | 居中，图片下方 |
| 页眉文字 | 居中 |
| 页脚页码 | 居中 |
| 表格内容（文字列） | 左对齐 |
| 表格内容（数字列） | 右对齐 |
| 注意事项/提示框 | 左对齐，整体缩进 4 字符 |

## 颜色方案

- 主色调：深蓝 #1F4E79（标题、表格表头、分隔线）
- 辅助色：中蓝 #2E75B6（二级/三级标题、链接）
- 正文色：纯黑 #000000
- 次要文字：深灰 #555555（题注、脚注）
- 页眉页脚：浅灰 #888888
- 提示框背景：浅黄 #FFF8E1
- 强调标记背景：浅蓝 #E8F0FE
- 表格表头文字：白色 #FFFFFF
- 表格表头背景：深蓝 #1F4E79
- 表格奇数行背景：白色 #FFFFFF
- 表格偶数行背景：极浅蓝 #F2F7FB

## 表格规范

- 表格整体居中对齐
- 内外边框均为 0.5pt 实线，颜色 #1F4E79
- 表头行高不小于 0.8cm
- 数据行高不小于 0.6cm
- 单元格内边距：上下 2pt，左右 5pt
- 表格与上下文之间保留至少一行空行（段后 12pt）
- 表格宽度默认占满版心（约 160mm），列宽按内容比例分配

## 图片规范

- 图片居中放置
- 最大宽度不超过版心宽度（约 160mm）
- 保持原始纵横比，禁止拉伸变形
- 每张图片下方添加居中题注，格式 "图 N：说明文字"，宋体 9pt，颜色 #555555，斜体
- 图片与上下文之间保留至少段后 12pt 间距
- 优先使用 `codex使用截图.png` 说明交互过程
- 如果版面合适，再使用 `codex使用效果截图.png` 展示完成效果

## 封面设计

- 文档标题：黑体 26pt，加粗，颜色 #1F4E79，居中，位于页面垂直中部偏上
- 副标题（如有）：宋体 14pt，颜色 #555555，居中，标题下方 24pt
- 封面不显示页眉和页码
- 封面之后另起一页开始正文

## 目录（可选）

- 如果文档超过 4 页，在封面之后、正文之前插入自动目录
- 目录标题使用一级标题样式
- 目录页码右对齐，前导符使用点线

## 内容侧重点

- 先用简洁语言说明 Codex 与普通代码问答工具的区别
- 重点介绍真实工程目录中的工作方式、修改与验证闭环
- 给出开始任务、观察长流程、处理常见故障和交付结果的实践建议
- 说明 tmux、测试、输出路径和 MCP 端口隔离等容易被忽略的问题
- 对安全边界和需要人工确认的情况做简短提醒
- 全文不少于 1000 字，建议在 1200–2000 字范围内

## 资源建议

- 两份文字资料都应作为内容依据，但需要合并重复信息，不能直接拼接
- 图片应保持原始纵横比，并添加简短题注
- 使用一个表格总结 Codex 的关键使用方法（至少含 4 列：操作、命令/方式、说明、注意事项）
- 全文至少包含 1 个表格

## 表达建议

- 语气专业、直接，避免宣传式措辞
- 使用清晰的一级、二级标题
- 操作步骤使用有序列表
- 风险和注意事项使用无序列表或提示段落（带背景色）
- 关键术语首次出现时使用加粗标记

以上为完整格式建议。工作流应以此为基础生成文档，可根据实际资源内容微调结构，并在生成报告中逐项说明格式规范的采纳情况与任何偏离原因。
