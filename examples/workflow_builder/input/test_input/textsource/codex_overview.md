# Codex 概览

Codex 是面向真实软件工程任务的编程 Agent。它可以进入现有工作区，读取项目文件、搜索代码、执行命令、编辑多个文件，并根据测试和命令输出继续修复问题。

它与普通代码问答工具的主要区别在于：Codex 不只给出建议，还能够围绕一个明确目标完成实际操作。典型任务包括理解陌生项目、定位错误、实现功能、补充测试、修改配置、整理文档和准备迁移。

## 核心能力

- 读取并理解多文件工程
- 搜索符号、调用关系和配置引用
- 使用补丁方式修改文件
- 执行测试、构建和检查命令
- 根据失败日志继续修复
- 保留已有代码风格和工程约束
- 汇总修改结果和剩余风险

## 协作方式

开发者给出目标和必要约束后，Codex 会先检查代码库和运行环境，再决定修改位置。对于需要较长时间的任务，可以使用 tmux 保留共享终端，让人工随时接入观察。

重要修改完成后，需要运行与风险匹配的验证。不能只确认命令执行结束，还应检查生成文件、测试报告和关键输出内容。

## 适用场景

Codex 适合处理具备明确输入、输出和验收方式的工程任务，例如：

- 修复可复现的软件缺陷
- 增加小型或中型功能
- 为已有模块补充测试
- 构建自动化工作流
- 整理项目文档和 quickstart
- 准备可迁移的工程包

对于缺少验收条件、涉及不可逆数据操作或需要产品决策的任务，仍应保留人工确认。
