# UCAgent 三大交互模式总览

UCAgent 底层验证流程、文件产出、31 阶段校验体系完全统一，仅大模型对接方式、操作终端、交互载体存在区分，三套为完全独立使用方案：

## 1. MCP 集成协同模式

双终端架构，UCAgent 作为 MCP 服务暴露验证工具，Codex/Claude/Cursor 等外部客户端独立运行，通过 MCP HTTP 协议远程调用验证能力；`--tui` 仅作为日志查看窗口，AI 对话操作在 Codex 客户端执行。

适用：需要对接第三方 IDE、外部大模型智能体、对外提供标准化工具接口。

## 2. 纯 TUI 本地直连模式

单终端原生交互，UCAgent 进程直接读取 `setting.yaml` 或系统环境变量中的大模型密钥，无需额外 Codex 客户端；TUI 面板同时承载日志、指令输入、人工审核全流程，无跨进程通信。

适用：本地快速调试、轻量化单模块验证、不希望开启多终端。

## 3. Master Web 可视化交互模式

内置 Web 服务，浏览器可视化面板替代终端命令，一站式完成 RTL 上传、编译、任务调度、人机协同；底层复用 TUI 完整校验逻辑，所有交互指令封装为可视化按钮，降低操作门槛。

适用：新手入门、团队多任务并行验证、需要可视化监控复盘。
