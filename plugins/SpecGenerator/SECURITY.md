
# Security Policy

本插件主要处理公开硬件源码和本地生成文档。README 示例工作区位于 UCAgent 忽略的 `output/` 下；其他工作区需自行排除输入、产物、本地配置及 `.ucagent/`（含工具凭据密钥），已跟踪文件仍会被 Git 记录。`.gitignore` 不是安全边界。请不要在产物、日志、参考资料或 Git 历史中保存或提交：

- API token、SSH private key、密码或 cookie。
- 内部仓库凭据和未公开下载地址。
- 含用户名、访问令牌或私有目录结构的本机绝对路径。
- 未授权公开的设计资料。

引用外部材料时，应确认其许可和再分发条件，并按 [维护指南](CONTRIBUTING.md) 记录来源与用途。模块产物需要长期保存时，应使用具备适当访问控制的项目外制品存储。

工具凭据用于检测证据是否被修改，不能代替操作系统隔离。生成 Agent 不应获得任意 Shell、修改插件或工具链、读取凭据密钥的能力；UCAgent 的工具过滤不能约束命令行后端自带的工具。

发现凭据泄露时，应立即撤销凭据并联系仓库维护者处理历史清理，不要仅通过后续 commit 删除文件。

漏洞报告与披露流程统一遵循 [UCAgent 安全策略](https://github.com/XS-MLVP/UCAgent/blob/main/SECURITY.md)。
